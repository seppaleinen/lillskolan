# Contributing to Lillskolan

Guidelines for contributing to the Lillskolan / Reading Academy codebase.

## Stack

- pnpm monorepo (Vite multi-page, TypeScript, Vitest)
- Packages: `apps/hub`, `apps/lessons/phonics-cvc`, `packages/lesson-sdk`
- All content and UI is in Swedish

## Commands

```bash
pnpm install          # install dependencies
pnpm verify           # typecheck + test + build (root)
pnpm --filter <pkg> dev   # run a single app
```

Pre-commit hooks (Husky) automatically run typecheck + tests on changed packages
and enforce the binary asset gate below.

## Binary asset policy (Git LFS)

**See [ADR-0009](docs/adr/0009-binary-asset-policy.md) for the full policy.**

### Rule

- **Files >10 MB must be tracked by Git LFS.** No exceptions.
- Files with these extensions are automatically routed through LFS via
  `.gitattributes`: `*.onnx`, `*.bin`, `*.model`, `*.safetensors`.
- The pre-commit hook **rejects** any staged file >10 MB without LFS tracking.
- CI (`binary asset audit` job) re-checks every push/PR.

### Setup (one-time)

```bash
brew install git-lfs        # macOS (or: sudo apt install git-lfs)
git lfs install             # set up hooks for this machine
```

### Committing a new binary asset

```bash
# If the extension is already covered by .gitattributes (*.onnx etc.) — just:
git add model.onnx
git commit -m "feat: add model"

# If you need to track a new extension, add it first:
git lfs track '*.pt'
git add .gitattributes model.pt
```

### Model weights (Piper TTS)

`piper-voices/sv_SE-alma-medium.onnx` is stored in Git LFS. It is materialized
automatically on clone/checkout when `git-lfs` is installed. If your clone shows
a 133-byte pointer file instead of the 60 MB model, run:

```bash
git lfs pull
```

### Why not just put models in an artifact registry?

The Piper voice file is small enough that LFS is simpler for this team. When the
model set grows beyond ~200 MB, revisit the policy (GitHub Release / Hugging Face
Hub distribution) — tracked as a follow-up on issue #21.

## Audio assets

- Phoneme WAVs in `apps/lessons/phonics-cvc/public/phonemes/` are **gitignored**
  (generated by `scripts/generate-full-onset-set.mjs`); 25 canonical clips remain
  tracked.
- New words: add clips + run `pnpm update-manifest` (see
  `scripts/update-manifest-from-clips.mjs`) — zero code changes.
- Validation: `pnpm validate-audio` checks 44.1 kHz mono 16-bit, non-silent.

## Audio generation (Piper TTS)

```bash
# One-time setup
python3 -m venv .venv && .venv/bin/pip install piper-tts
git lfs pull            # ensure piper-voices/sv_SE-alma-medium.onnx is present

# Generate all onset+vowel combos
node scripts/generate-full-onset-set.mjs
```
